# DreamRun

A visual novel engine built on Svelte 5.  
Scenarios are written in `.dreamrun` files, a custom scripting language.

This document covers **setup & run only**. For full engine documentation, see the
project Wiki.

---

## Requirements

| Component | Minimum | Notes |
|---|---|---|
| Node.js   | 18.x    | 20.x recommended |
| npm       | 9.x     | ships with Node 18+ |
| OS        | Windows, Linux, macOS | tested on Windows 10/11, Debian 12, macOS 14 |

---

## Quick Start

From the repository root:

```bash
# Prepare the workspace
npm install
# Dev launch
npm run dev
```

After that, you can go to `localhost:5173` and test the engine template novel, and... *make something yours!*
